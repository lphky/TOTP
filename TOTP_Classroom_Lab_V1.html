原理拆解 · How It Works

可以先收起，講解時再展開，減少學生負擔。

Unix Time · 秒—
Time Counter = floor(time / 30)—
演算法HMAC-SHA1
截取結果 mod 1,000,000—
Secret Key + Time Counter → HMAC-SHA1 → 動態截取 → 六位數 OTP

兩個裝置的時間不需要互聯同步，只要系統時鐘足夠準確、Secret Key 一致，就能得到相同結果。時區不影響 Unix Time；時鐘偏差會影響 OTP。
